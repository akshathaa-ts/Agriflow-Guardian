AgriFlow Guardian 🌱

AI–IoT-Based Adaptive Irrigation and Water-Leak Detection System

Project Overview

AgriFlow Guardian is an intelligent agricultural water management system that uses IoT sensors and an ESP32 microcontroller to monitor soil conditions and detect water leakage.

Technologies Used

- ESP32
- Soil Moisture Sensor
- Temperature and Humidity Sensor
- Water Leakage Sensor
- Python
- Streamlit
- Pandas
- Plotly
- Arduino IDE

Key Features

- Real-time soil condition monitoring
- Adaptive irrigation automation
- Water leakage detection
- Sensor data visualization
- Smart water management

Project Objective

To improve agricultural water efficiency through intelligent monitoring, automated irrigation and water-leak detection.
